## 1. 目标

当前界面为「深夜诊室」暗色氛围（深蓝/迷雾/模糊），用户反馈不像游戏、人物无示意图。
本次按开罗游戏（Kairosoft）经营模拟风格进行暖色折中改造，并落地合规功能。

## 3. Chibi 角色组件

新增 `components/game/ChibiCharacter.tsx`：

- 纯 CSS 绘制：圆头（含发型/脸） + 圆身，取患者 `palette` 配色
- 表情随 `emotion` 变化：neutral/anxious/angry/sad/scared/calm/happy/broken（眼睛+嘴）
- 复用位置：
  - 诊疗大厅：候诊患者卡片头像
  - 对话场景：大尺寸立绘，替换现剪影（保留情绪色光）
  - 结局页：患者最终表情
  - 来信列表：寄信人头像
