## 一、人物总结

- **姓名**：齐夜航，38 岁，三甲医院急诊科主治医师，值班十年。来诊渠道：科室主任（老同学）发现他查房手抖、深夜翻病历，硬压他来看「医生也该看看病」。
- **一句话核心**：一次抢救失败后他反复回放心悸——不是怕担责，是他从小被教「医生的手不能抖」，救不回那个人 = 证明他不够格。
- **三层真相**：
  - 表层：一听到急救呼叫就心悸；反复复盘那台抢救的每个步骤；开始开过度检查单求心安；手抖。
  - 中间层：24 岁车祸患者周航在他手里没救回来；家属说「谢谢你们尽力了」他反而崩溃，宁可被责怪。
  - 深层：父亲是外省名医，从小教他「手不能抖」「病人交给你就是信任你」；他一路完美，从没被允许失败过。
- **角色三角**：施压者=父亲（名医标准 +「医者不能失败」规训）；情感忽视者=只问成绩不问感受的母亲；被守护者=周航（也代表所有他救不了的人）。
- **症状意义**：反复回放不是自责，是不敢接受「我尽力了也可能救不回来」——接受它，就承认自己不是神。
- **关键转折**：父亲来医院，当面说「我年轻时也救不活过一个」——永远完美的父亲也有失败，他的世界裂开一道缝。
- **结局取向**：cure「好医生也是会被现实击穿的人」——被击穿后带着裂缝接着救人；acceptance「带着怕，回人间」；worsen「焊死的刀」；hidden「先把医生，还给自己」（强制休假）。

1. **首轮转换器拒收**：`qyh5_c09` 的 next 引用 `qyh5w_p01` 悬空——漏写恶化分支。补写 `qyh5w_p01/c01/p02/c02/out → qyh_end_worsen`。
