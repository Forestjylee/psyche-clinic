## 一、人物档案摘要

**姓名** 林晚玉，35 岁，国企行政专员，办公室公认的「老好人」。来诊渠道：单位体检胃溃疡，领导注意到她总替人加班，劝她来看看。

**一句话核心**：她帮所有人，唯独不帮自己——不是她善良到没脾气，是她从小被「你不乖就不喜欢你」吓大，拒绝=失去，讨好是她活下去的生存策略。

**三层真相**
- 表层（开场就说）：胃溃疡、失眠、习惯性微笑。同事的活都堆给她，她笑着说「没事」；请个假都要纠结半天；把「被需要」当「被喜欢」。
- 中间层（第 2-3 节拍揭）：升职被关系户顶掉，她不敢争取只敢深夜哭；妈妈从小就说「你要懂事」「别给人添麻烦」；她帮得越多越怕停。
- 深层（核心信念，根源）：童年只有考好、乖，才换得到妈妈一个笑脸。她学会用「有用」换「被爱」，活成了所有人的备选。拒绝的代价她从小就付不起——说不=被丢下（源自八岁那块橡皮）。

**角色三角**：施压者=单位里习惯使唤她的同事 + 「你要懂事」的家教；情感忽视者=只在她「有用」时才看见她的妈妈；被守护者=那个怕被抛弃的小孩。

**症状意义**：讨好不是软弱，是她活下去的生存策略——八岁起用「帮忙/懂事/有用」换一句笑脸。开场埋（她帮所有人、笑着说没事）、中段被问（帮越多越怕停、被需要=被喜欢）、高潮意义反转：讨好救过小时候的自己，却掐着三十多岁的自己的脖子。

**关键转折**：她照例答应帮人加班，回家照镜子突然认不出自己——发现自己已经不会说「不」了（节拍4，lwy4_start）。真正的情感顶点是节拍5：她向老周说出「这次不行」，回家哭了很久——不是因为委屈，是因为终于知道，不用靠帮忙，也能被人好好对待。

**写作处理**：核心是「讨好不是性格，是伤」；结局偏向「第一次说出拒绝，世界没有塌」。全程不出现治疗术语与患者口述时间词。
