## 一、人物档案摘要

**姓名** 安宁，25 岁，小公司会计，独居租在老小区。被闺蜜发现她删光聊天记录躲着哭，硬拖她来。

**一句话核心**：被骗的是钱，也是她第一次以为被爱——她恨的不是骗子，是那个「居然相信」的自己。

**三层真相**
- 表层：不敢报案、不愿提，觉得「丢人」；删光一切关于那个人的痕迹，把手机扣在桌上。
- 中间层：网恋三个月、对方是「外派工程师」，以周转为由分三次借走她全部积蓄 8 万后消失；闺蜜早提醒过她，她没听。
- 深层：从小被教「要懂事」「别给人添麻烦」，她从不敢对任何人开口说「我想要」——所以那个人「每天说想她」的时候，她第一次觉得被人惦记。

**角色三角**：施压者=那个消失的「他」（一场精心设计的骗局）；情感忽视者=忙于生计、只问「钱还够吗」的父母；被守护者=她心里那个想被爱的小女孩。

**症状意义**：自责是她的防御——只要把错都归给自己（「是我蠢」），就不用面对更痛的事：「原来没有人真的爱我」。

**关键转折**：骗子照片里的人设几乎是她理想中自己的样子——她不是被骗了钱，是被「她渴望成为的自己」骗了（节拍3，an3_p06）。

**写作处理**：不妖魔化受害者，突出「渴望被爱不是错」；结局走「敢报案 / 敢对闺蜜说出『谢谢你惦记我』」。
