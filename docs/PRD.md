## 1. 产品定位

### 1.1 一句话定义
**一款「让普通人也能体验到倾听与陪伴价值」的心理医生模拟器**——通过对话诊疗影响患者结局，在经营诊所的过程中，养成医者之心。

### 1.2 核心理念（必须贯穿全产品）
> 你不必是心理学家，也能成为某个人暗夜里的那束光。

这是本作区别于「心理咨询专业教学软件」的根本差异点：

- **不堆砌术语**：心理学专业词汇以「悬停浮窗」轻量化解释，绝不成为通关门槛。
- **不考诊疗方法**：没有标准答案，没有「正确话术」。玩家的选择反映的是「你愿意怎样对待面前这个人」，而非「你背了多少教科书」。
- **强调情绪价值**：每一次接诊的反馈焦点，是「你给患者带去了什么」，而不是「你扣了几分」。
- **温暖承接失败**：坏结局不会被冰冷地惩罚，而是被温柔地承接——「不是你不够好，是有些事，一个人扛不动」。

### 1.3 目标用户
| 用户层 | 占比预期 | 核心诉求 |
| --- | --- | --- |
| 非心理学专业的成年人 | 70% | 体验帮助他人的成就感、情绪共鸣、轻度经营养成 |
| 心理学爱好者/学生 | 20% | 验证专业直觉、了解诊疗框架、收集结局 |
| 心理工作者 | 10% | 作为科普引子、向来访者传递「被听见」的感受 |

### 1.4 不做什么（明确边界）
- ❌ 不做临床诊断工具，不替代真实心理咨询。
- ❌ 不输出具体药物剂量、不提供「按这个方法做就能好」的承诺。
- ❌ 不做多人在线、不做 PVP 排行碾压。
- ❌ 不做付费数值膨胀（Pay to Win）。

## 2. 核心玩法循环

```
        ┌──────────────────────────────────────────┐
        │              标题屏 / 读档                │
        └────────────────────┬─────────────────────┘
                             ▼
        ┌──────────────────────────────────────────┐
        │            诊所大厅（经营主界面）          │
        │  患者预约列表 · 随机事件 · 技能/升级/信件   │
        └────────────────────┬─────────────────────┘
                             ▼
        ┌──────────────────────────────────────────┐
        │           诊疗对话（核心循环）             │
        │  共情/试探/直击/讲理/处方/催眠/沉默        │
        │  → 数值变化（信任/防御/心情/真相）         │
        │  → 触发连击、防御、真相揭示                │
        └────────────────────┬─────────────────────┘
                             ▼
        ┌──────────────────────────────────────────┐
        │            结局结算 + 温暖回响             │
        │  8 种结局 → 决定复诊倾向                   │
        └────────────────────┬─────────────────────┘
                             ▼
        ┌──────────────────────────────────────────┐
        │      患者生命周期：离场结案 / 复诊池       │
        │  治愈·接纳→离场；依赖→60%复诊；            │
        │  恶化·悲剧→永久离场；隐藏·觉醒·转介→25%    │
        └────────────────────┬─────────────────────┘
                             ▼
        ┌──────────────────────────────────────────┐
        │   休息一天：随机事件 + 复诊 roll          │
        │  + 候诊等待推进 + 补充新患者              │
        └────────────────────┬─────────────────────┘
                             │
                             └──→ 回到诊所大厅
```

## 3. 功能清单

### 3.1 核心功能（v1.0 必须达成）

| 模块 | 功能点 | 验收标准 |
| --- | --- | --- |
| 标题屏 | 主题传达、读档、新游戏 | 副文案传递「倾听即治愈」理念；自动存档可续玩 |
| 诊所大厅 | 患者列表、办公桌菜单、资源 HUD | 引导语温暖；锁定/已完成状态清晰 |
| 诊疗对话 | 8 类话术（共情/试探/直击/讲理/处方/催眠/沉默/特殊）、数值系统、连击、防御机制 | 单次接诊 5-15 分钟可完成；至少 1 个连击演示 |
| 患者剧本 | 首发至少 3 个手写剧本 | 每个剧本有「表象-真相」结构，结局分支 ≥ 3 |
| 剧本生成器 | 程序化生成新患者 | 生成的剧本可玩、不穿帮；素材库 ≥ 500 条 |
| 复诊系统 | 结局决定复诊倾向 + 独立复诊剧情 + 复诊施压 | 三层生命周期自洽；复诊产出结局、报酬递减、配复诊记忆碎片；复诊次数上限可玩 |
| 随机事件 | 休息时约 80% 概率触发事件 + 决策 + 影响 | 事件素材 ≥ 100 条；决策可取舍、不惩罚；与复诊 roll 相互独立 |
| 结局系统 | 8 种结局类型 + 温暖回响 | 每种结局有差异化文案；坏结局被温柔承接 |
| 成就系统 | ≥ 30 个成就 + 高品质解锁特效 | 4 级稀有度差异化；传说级有金环特效 |
| 技能树 | 4 大流派、解锁/前置 | 精神分析/CBT/催眠/药物学 4 流派 |
| 诊所升级 | 设施升级影响初始数值 | 5 项设施 × 3 级，效果递增 |
| 金钱经济 | 诊所经营资源：接诊赚钱 → 升级/道具/广告 | 多级升级（2 级≈1.8×价、3 级≈2.5×价）+ 消耗品（50-200 金）+ 广告（300 金/次，新患者 +1 持续 3 天） |
| 信件系统 | 患者回信、感谢信/暗黑信 | 情感延续，强化「你影响了一个真实的人」 |
| 存档 | 本地自动存档 + 手动存档 | 切换设备时数据隔离可接受；不丢档 |
| 音频 | BGM + 关键音效 | 理智值影响 BGM 滤波；尊重静音设置 |
| 无障碍 | prefers-reduced-motion 降级 | 关闭粒子/脉动，仅保留淡入 |

### 3.2 公测品质强化项（v0.2 已完成）

- ✅ **温暖文案全覆盖**：标题屏、诊所大厅、结局回响、成就描述四个关键节点统一传递「倾听即治愈」。
- ✅ **成就解锁全屏特效**：暗场聚焦 → 光晕脉动 → 卡片迸发 → 粒子爆裂 → 文字级联，4 级稀有度差异化，传说级金环。
- ✅ **理智值动态影响 BGM**：低理智时滤波器下沉，营造压抑氛围。

## 4. 体验设计原则

### 4.1 文案准则
1. **第二人称「你」**：始终把玩家放在「主动陪伴者」的位置。
2. **避免诊断口吻**：不写「该患者患有 X」，改写「她看起来……」。
3. **承接而非评判**：坏结局不写「你失败了」，写「这份难过，恰恰说明你在乎」。
4. **专业词轻量化**：浮窗一句话解释，不展开诊疗流程。

### 4.2 视听准则
1. **深夜诊室基调**：深蓝紫色调，金色点缀，营造「安静、被守护」的氛围。
2. **仪式感优先**：成就解锁、结局结算必须有「停一停」的仪式感，不可一闪而过。
3. **情绪驱动音效**：BGM 随理智变化，关键节点有专属音效。
4. **可访问性兜底**：所有动画提供 reduced-motion 降级。

### 4.3 数值准则
1. **不惩罚探索**：选错话术扣的是「心情/信任」，不是直接 Game Over。
2. **坏结局有意义**：坏结局也产出信件、成就、理智波动，是叙事的一部分。
3. **长线养成**：单次接诊 5-15 分钟，整体通关 8-15 小时。

## 7. 风险与对策

| 风险 | 等级 | 对策 |
| --- | --- | --- |
| 误导玩家以为可替代真实咨询 | 高 | 标题屏 + 结局页免责声明；提供「寻求专业帮助」入口 |
| 坏结局引发玩家不适 | 中 | 温暖回响承接；提供「跳过悲剧演出」选项 |
| 生成器剧本穿帮/雷同 | 中 | 模板组合 + 真相库去重；保留 ≤ 5 个 |
| 术语解释不准确 | 中 | 词条标注来源（DSM-5/ICD-11）；邀请专业审校 |
| 数据丢失 | 中 | 本地多 slot 存档 + v1.1 云同步 |

## 8. 免责声明（必须出现在产品中）

> 本作是一款以「倾听与陪伴」为主题的互动叙事游戏，旨在让更多人感受到被听见的温度。
> 游戏中的心理学概念为创作简化，**不构成**任何临床诊断、治疗建议或药物指导。
> 如果你或身边的人正在经历心理困扰，请寻求专业心理咨询师或医疗机构的帮助。
