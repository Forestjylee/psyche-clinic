## 2. M3 公测发布（v1.0）任务分解

### 2.1 核心玩法重构：复诊系统（P0）
- [ ] 患者三层生命周期（候诊/已诊疗/离场）+ 复诊系统
  - [ ] 数据层：GameState 新增 `discharged`/`followUpCount`；PatientScenario 新增复诊剧情结构（`followUpDialogues`/`followUpStart`/`maxFollowUps`）
  - [ ] 每日结算：治愈/接纳/恶化/悲剧离场移除；依赖（60%）、隐藏/觉醒/转介（25%）按概率 roll 进当日候诊；复用复诊剧情
  - [ ] 大厅 UI：预约列表区分初诊/复诊/离场，复诊卡片标注「第 N 次复诊」
  - [ ] 追踪档案：显示患者当前状态（已治愈离场/依赖复诊中/放弃治疗）
  - [ ] 复诊剧情：3 个现有手写剧本（林晓/周明远/陈洛）各补独立复诊对话
  - [ ] 结局动态判定：真相度 + 关键抉择综合判定结局（替代仅 `isEnding` 写死）

**验收**：接诊→离场/复诊全流程走通；复诊内容与初诊不重复；存档兼容。

### 2.2 随机事件系统（P0）
- [ ] 事件引擎：每日「休息」触发随机事件，提供 2-3 个决策选项 + 资源影响（声望/理智/金钱/候诊）
- [ ] 事件素材库 ≥ 100 条（日常 40 / 行业 20 / 情感 20 / 特殊 20）
- [ ] 大厅事件横幅 UI + 结果消息写入消息盒子

**验收**：长玩不无聊；事件决策可取舍、不惩罚；文案符合「倾听即治愈」理念。

### 2.3 生成器素材库扩充至 500+ 条（P0）
- [ ] 素材库总量 ≥ 500 条，保证长玩不腻
  - [ ] 姓名池 100 条（男女各 50）
  - [ ] 职业 20 套（当前 8）
  - [ ] 表象（症状）20 套（当前 6）
  - [ ] 真相模板 24 套（当前 18，每个含完整对话图）
  - [ ] 信件模板 ≥ 30 封（当前 15 目标）
  - [ ] 心理学词条 ≥ 60 条，标注 DSM-5/ICD-11 来源
  - [ ] 复诊/结案文案、心情描述等杂项素材补齐

**验收**：组合去重无穿帮；同一天两次生成不出现完全相同剧本；生成剧本含复诊剧情。

### 2.4 内容扩充：手写剧本（P0）
- [ ] 手写患者剧本扩充至 5 个（当前 3 个：林晓/周明远/陈洛）
  - [ ] 患者D：青少年自伤（悲剧/隐藏分支，需谨慎处理）
  - [ ] 患者E：老年人孤独（治愈/接纳分支）

**验收**：每个剧本 ≥3 结局分支 + 独立复诊剧情。

### 2.5 合规与安全（P0）
- [ ] 标题屏新增「免责声明」入口（折叠展开）
- [ ] 结局页固定显示「寻求专业帮助」卡片（含全国心理援助热线 400-161-9995）
- [ ] 悲剧结局提供「跳过演出」选项，记忆设置
- [ ] 自伤/自杀相关剧本内容审核（邀请专业审校）

**验收**：免责声明在标题屏与结局页可见；热线信息准确；敏感内容有跳过兜底。

### 2.6 工程与部署（P0）
- [x] 文档体系建立（PRD/Spec/Plan/Deployment）

## 5. 长期维护原则

1. **理念优先**：所有新功能必须服务「让普通人体验倾听价值」的核心理念，违背则不做。
2. **内容可独立维护**：剧本/词条/成就数据存放 `lib/data/`，策划可独立修改不影响逻辑。
3. **引擎可测**：业务规则集中在 `lib/engine/`，保持纯函数，任何 UI 改动不破坏逻辑正确性。
4. **迁移平滑**：持久化经 `StorageDriver` 抽象，未来切 KV/D1 业务层零改动。
5. **文档同步**：每次发版必须同步更新 PRD/Spec/Plan 的变更记录与版本号。
6. **版本号语义**：`MAJOR.MINOR.PATCH`——理念/架构变更升 MAJOR，功能新增升 MINOR，修复升 PATCH。
