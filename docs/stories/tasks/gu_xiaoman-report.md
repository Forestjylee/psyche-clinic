## 1. 人物档案摘要

- **姓名 / 年龄 / 职业**：顾小满，22 岁，舞蹈专业应届毕业生（备考艺考 / 找舞蹈团）。
- **来诊渠道**：练功晕倒送校医室，老师发现她长期只吃水煮菜，劝她来心理门诊。
- **一句话核心**：把身体当作被爱的入场券，瘦是她的成绩单。
- **三层真相**
  - 表层：不敢穿合身衣服、睡前摸肋骨确认「还在瘦」、拒绝晚饭、天天称重、睡前把衣服尺码过一遍。
  - 中间层（节拍 2）：舞蹈老师「你腰上有肉」一句玩笑当判决；男友约会总点沙拉（「你再忍忍，快了」）；体检被警告营养不良，她笑说「正常，跳舞的都这样」。
  - 深层（节拍 3）：妈妈从小夸「瘦的才漂亮」，瘦 = 妈妈的抱 = 被爱。她拿腰腿肋骨尺码去换夸奖，把身体活成了妈妈的「作品」。
- **角色三角**：施压者 = 舞蹈老师（量合不合格的尺）；情感忽视者 = 妈妈（只夸瘦，从不夸她本身）；被守护者 = 镜子里那个「理想的自己」（节拍 4 橱窗倒影认不出自己）。
- **症状意义**：节食 / 控制进食是她唯一能完全掌控的事——舞由评委说了算，只有瘦由她自己说了算。瘦是拿身体去换「被爱」的入场券。
- **关键转折**：路过服装店橱窗，看见倒影里瘦到脱相的自己，认不出那是谁 → 她说「我挺心疼她的」→ 转向身体和解。
- **写作注意遵守**：全程只写「不吃晚饭 / 水煮菜 / 反复称重 / 摸肋骨 / 尺码过一遍」，零催吐细节。
