# 暖心小诊室 · 核心玩法术语表（Glossary）

> 定义游戏内与设计文档共用的术语，避免歧义。与 [SPEC §3.4](../SPEC.md) 相互印证。

| 术语 | 英文/字段 | 定义 |
| --- | --- | --- |
| 候诊区 | 候诊（初诊候选） | 从未接诊、声望达标、未结案的患者。累计 `waitingDays`，满阈值病情加重/放弃治疗。 |
| 已诊疗 | `patientRecords` | 至少完成一次会话、已有结局的患者。 |
| 离场/结案 | `discharged` | 不再复诊的患者（治愈/接纳/恶化/悲剧/达复诊上限），从预约列表消失，追踪档案保留结案记录。 |
| 复诊池 | 复诊池 | 已诊疗且可复诊的患者（依赖/隐藏/觉醒/转介结局 roll 命中进入）。每日参与复诊 roll。 |
| 复诊中 | 追踪档案状态 | 复诊池患者在追踪档案中的显示状态（区别于「已治愈离场」「候诊中」）。 |
| 复诊 roll | `rollFollowUps` | 每日结算对复诊池患者按结局概率抽签，命中→今日预约、未命中→等待天数+1。 |
| 初诊 | `startNode` | 患者第一次会话，走完整对话树，产出结局，可能触发记忆碎片。 |
| 复诊 | `followUpDialogues` | 复诊池患者的后续会话，走独立短剧情（3-5 节点），产出复诊结局。 |
| 复诊次数上限 | `maxFollowUps`（默认 2） | 复诊达到该次数即结案离场。 |
| 复诊等待/放弃复诊 | `followUpIdleDays` | 复诊池患者久不复诊的等待天数，满 `FOLLOW_UP_GRACE_DAYS` 放弃复诊、扣声望、离场。 |
| 复诊记忆碎片 | `followUpFragments` | 复诊剧情中触发的新记忆碎片（初诊碎片不重复）。 |
| 复诊回信 | — | 复诊结束后产出的简短回信，体现患者变化。 |
| 复诊报酬 | — | 复诊报酬递减：初诊 70%，第 2 次复诊约 40%。 |
| 复诊结局 | `EndingType` | 复诊结束时产出；治愈/接纳→离场，依赖→继续复诊，恶化/悲剧→离场。 |
| 结局复诊倾向 | `FOLLOW_UP_CHANCE` | 各结局进入复诊池的概率：治愈/接纳 5%、依赖 60%、恶化/悲剧 0%、隐藏/觉醒/转介 25%。 |
| 多级设施升级 | `ClinicUpgrade.level` | 现有设施各扩到 3 级，效果递增（2 级 ≈1.8×价、3 级 ≈2.5×价），金钱主要消耗口。 |
| 消耗品 | 道具 | 一次性购买的药品/道具（50-200 金），会话中解锁选项或提升治愈率。 |
| 广告拉新 | — | 300 金/次，提升每日新患者上限 +1，持续 3 天。 |

## 患者生命周期流转

```
候诊区（初诊候选）
   │ 接诊，走完整对话树
   ▼
已诊疗（有结局）
   │ 按结局复诊倾向 roll
   ├─ 治愈/接纳(5%)、恶化/悲剧(0%) → 离场结案
   ├─ 依赖(60%)、隐藏/觉醒/转介(25%) → 复诊池
   │     └─ 每日复诊 roll：命中→今日复诊（短剧情→复诊结局）
   │         ├─ 治愈/接纳 → 离场结案
   │         ├─ 依赖 → 继续复诊池（至多 2 次）
   │         └─ 恶化/悲剧 → 离场结案
   │     └─ 久不复诊 → 放弃复诊（扣声望）→ 离场
   ▼
离场/结案（追踪档案保留记录）
```
